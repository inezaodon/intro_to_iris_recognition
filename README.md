# Intro to iris recognition

Overnight study site for [John Daugman’s 2004 paper](https://www.cl.cam.ac.uk/~jgd1000/irisrecog.pdf) *How iris recognition works*, plus the Notre Dame / NIST IREX stack (ArcIris).

## Local

Open `index.html` in a browser, or:

```bash
python3 -m http.server 8080
```

Then go to [http://localhost:8080](http://localhost:8080). The **Daugman 2004** tab is a keyboard-driven slide deck (`←` `→` or space).

## What is in here

| Tab | Purpose |
| --- | --- |
| Start here | Tonight’s plan and the four sources Adam sent |
| Pipeline | The six steps every iris matcher still uses |
| Daugman 2004 | Full walkthrough of the paper, written to be studied not skimmed |
| Deep learning | Where neural nets actually help vs IrisCode |
| ArcIris | The Notre Dame method you will work with (`ndcvrl_002`) |
| IREX | NIST identification metrics |
| Quiz | Meeting-ready questions |

This is a study aid, not a substitute for the papers.
